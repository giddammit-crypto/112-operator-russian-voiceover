# 112 Operator — Кинематографическая русская озвучка (Рация и Звонки 112)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Platform: Linux / Proton / Windows](https://img.shields.io/badge/Platform-Linux%20%2F%20Proton%20%2F%20Windows-green.svg)](#)
[![Audio: WAV 44.1kHz 16-bit](https://img.shields.io/badge/Audio-WAV%2044.1kHz%2016--bit-orange.svg)](#)
[![Tests](https://img.shields.io/badge/tests-37%20passing-brightgreen.svg)](#-тесты)

Полная переработка русской озвучки **112 Operator**: переговоры экипажей по рации,
диалоги экстренных вызовов и фоновый радиоэфир — с актёрской подачей, эмоциями и
настоящим эфирным трактом, без иностранного акцента.

> **Версия 2.0** — озвучка пересобрана с нуля: новый литературный сценарий,
> собственный DSP-движок, система ролей и эмоций, параллельная сборка и тесты.
> Прежние скрипты с захардкоженными путями заменены пакетом `voicepack`.

---

## Что нового по сравнению с прошлой версией

| | Было | Стало |
|---|---|---|
| **Речь** | калька с английского, однотипные фразы, мат через строку | живая речь служб МВД/МЧС/СМП, реальные формулы радиообмена, разная длина реплик |
| **Голоса** | 2 голоса TTS на 4 роли — экипажи звучали одинаково | 4 роли × 2 «актёра» = 8 различимых голосов + пул звонящих |
| **Эмоции** | грубая подстройка темпа и высоты | 27 эмоций: дрожь голоса, одышка, вдохи, надрыв, перегруз от крика |
| **Обработка** | одна цепочка ffmpeg на все файлы | собственный DSP: свой тракт у каждой роли, PTT, squelch, roger-beep, потери связи |
| **Текст** | «112» читалось как «сто двенадцать»… или нет | нормализация чисел, сокращений, аббревиатур, транслитерация латиницы |
| **Зависимости** | ffmpeg + edge-tts обязательны, пути автора в коде | ffmpeg не нужен, 5 сменных TTS-бэкендов, пути определяются автоматически |
| **Контроль** | скрипт «файл существует» | проверка формата, клиппинга, тишины, разброса громкости + 37 тестов |
| **Сборка** | последовательная | параллельная по процессам |

## 🎙 Кастинг

### Экипажи на рации

| Роль | Образ | Звуковой характер |
|---|---|---|
| **Male1** | Командир экипажа | Низкий тембр, уставная дикция, спокойствие под давлением. Узкая полоса 330–3300 Гц, мягкая АРУ, роджер-бип |
| **Male2** | Боец группы захвата | Быстрая речь на адреналине, кричит в тангенту. Перегруз передатчика, жёсткая компрессия 8:1, провалы связи |
| **Female1** | Координатор смены | Чеканная командная речь, номера и позывные. Чистый канал, минимум шума |
| **Female2** | Патрульная на передовой | Живые эмоции, надрыв в критических ситуациях. Горячий канал, сатурация от крика |
| **Chatter** | Фоновый эфир дежурной части | Тише и глуше — «в соседней комнате»: диалоги с ответами, ориентировки, проверки по базам |

Каждая роль звучит **двумя актёрами**: нечётные дубли реплики читает основной голос,
чётные — вариант с другим тембром. В эфире слышен разный личный состав, а не один диктор.

### Звонки 112

- **Оператор** — спокойный профессионал в гарнитуре: широкая полоса, студийная плотность,
  де-эссер. Экранные подписи кнопок `{ЧТО СЛУЧИЛОСЬ?}` не произносятся.
- **Звонящие** — пул из 8 «актёров массовки» (4 мужских, 4 женских). Голос выбирается
  детерминированно по вызову: внутри одного звонка человек не меняется, разные вызовы
  звучат разными людьми.
- **Телефонная линия** — полоса 330–3400 Гц, μ-law-кодек, потери пакетов, плюс акустика
  места события: улица, помещение, салон машины, толпа.

## 🎭 Эмоции

27 состояний, каждое влияет на подачу, тело голоса и тракт одновременно:

`panic` `shout` `combat` `crying` `pain` `dying` `fear` `angry` `hostile` `desperate`
`drunk` `whisper` `nervous` `confused` `tired` `sad` `relieved` `sarcastic` `urgent`
`tense` `calm` `formal` `child` `elderly` `neutral` …

Например, `panic` — это не просто «быстрее и выше»: добавляются дрожь голоса 6.5 Гц,
одышка, вдох перед фразой, +4.5 дБ компрессии и перегруз микрофона.

Для вызовов эмоция берётся из атрибута `emotions="..."` XML-сценария игры, а если он
пуст — определяется эвристикой по самой реплике (капс, восклицания, лексика).

## 🛠 Установка

### Быстрый способ (Linux / Steam Deck / Proton)

По умолчанию установщик теперь пересобирает **только звонки 112** — рацию экипажей
не трогает, если она у вас уже звучит нормально:

```bash
git clone https://github.com/giddammit-crypto/112-operator-russian-voiceover.git
cd 112-operator-russian-voiceover
./install.sh
```

Если всё же нужна полная пересборка вместе с рацией:

```bash
SCOPE=all ./install.sh
```

Если игра установлена нестандартно — укажите путь:

```bash
./install.sh "/путь/к/112 Operator"
```

Скрипт сам найдёт игру, сгенерирует озвучку, соберёт мод, установит его и проверит результат.
После этого запустите игру и включите мод **«Russian Radio Voiceover»** в меню **«Моды»**.

### Ручная сборка

```bash
# 1. Только рация, в локальную папку build/
python3 -m voicepack radio --out build

# 2. Звонки 112 (нужна установленная игра — берём тексты и XML оттуда)
python3 -m voicepack calls --game "/путь/к/112 Operator" --out build

# 3. Всё сразу
python3 -m voicepack all --game "/путь/к/112 Operator" --out build

# 4. Проверить качество пака
python3 -m voicepack verify --out build

# 5. Установить в игру
python3 -m voicepack install --out build --game "/путь/к/112 Operator"
```

### Демо перед полной сборкой

```bash
python3 -m voicepack demo --out build/demo
```

Сгенерирует десяток показательных реплик (бой, ранение, паника, погоня, звонок)
за пару минут — можно оценить звучание, не собирая весь пак.

## 🔊 Движки синтеза речи

Пак не привязан к одному TTS. Бэкенд выбирается автоматически (первый доступный),
либо задаётся флагом `--backend`:

| Бэкенд | Качество | Сеть | Комментарий |
|---|---|---|---|
| `edge` | ★★★★★ | нужна | Microsoft Edge TTS, голоса `ru-RU-DmitryNeural` / `SvetlanaNeural`. Рекомендуется |
| `piper` | ★★★★ | нет | Локальный Piper. Укажите модели: `PIPER_MODEL_DIR=/путь/к/onnx` |
| `silero` | ★★★★ | нет* | Silero TTS v4, дикторы aidar / baya / eugene / kseniya (*модель качается один раз) |
| `espeak` | ★★ | нет | Аварийный вариант: разборчиво, но роботно |
| `stub` | — | нет | Процедурный стенд: речи нет, проверяется тракт и тайминги |

```bash
pip install edge-tts            # рекомендуемый вариант
python3 -m voicepack all --backend edge --game "/путь/к/112 Operator"
```

**ffmpeg не требуется** — весь DSP реализован внутри проекта. Он используется только
для декодирования MP3 от Edge TTS, и то опционально: подойдёт `pip install miniaudio`.

## ⚙️ Как обрабатывается реплика

```
       текст сценария / локализации игры
                  │
       нормализация: 112 → «сто двенадцать», ул. → улице, снятие разметки
                  │
                 TTS
                  │
  обрезка «воздуха» → де-эссер → гейт
                  │
  ЭМОЦИЯ: дрожь голоса, одышка, вдох перед фразой, подача
                  │
  АНАТОМИЯ РОЛИ: varispeed + формантный наклон (свой тембр у каждого актёра)
                  │
  ТРАКТ: полоса рации 24–48 дБ/окт → presence → АРУ → сатурация усилителя
                  │
  СВЯЗЬ: μ-law-кодек → bit-crush → провалы сигнала
                  │
  ЭФИР: шип + треск, приседающие под речь (АРУ)
                  │
  МОНТАЖ: клик тангенты + речь + roger-beep + squelch-хвост
                  │
  МАСТЕРИНГ: нормализация по RMS → лимитер с look-ahead (без клиппинга)
                  │
          WAV 44.1 кГц / 16 бит / стерео
```

## ✅ Контроль качества

`python3 -m voicepack verify` проверяет не только наличие файлов:

- формат каждого клипа (44.1 кГц / 16 бит / стерео — иначе движок не загрузит);
- клиппинг и «мёртвые» (пустые или слишком тихие) файлы;
- разброс громкости между репликами — скачки уровня в эфире режут ухо;
- аномальные длительности (обрубленные и зависшие клипы);
- полноту покрытия ролей и категорий;
- регистрацию мода в `ScriptingAssemblies.json` и `RuntimeInitializeOnLoads.json`.

## 🧪 Тесты

```bash
python3 -m unittest discover -s tests -v
```

37 тестов покрывают нормализацию текста, разбор эмоций, DSP (лимитер сверяется
с эталонной реализацией), рендер во всех режимах, парсинг локализации и XML игры,
а также сквозную сборку. Сеть, ffmpeg и установленная игра не нужны — данные игры
подменяются фикстурой, речь синтезирует процедурный стенд.

## 🔧 Полезные флаги

```bash
--backend edge|piper|silero|espeak|stub|auto   движок синтеза
--jobs 8                                       параллельных процессов
--limit 20                                     ограничить число реплик (отладка)
--role Male2                                   собрать одну роль
--category underfire                           собрать одну категорию
--call c_car_crash                             собрать один вызов
--operator-voice female                        женский голос оператора 112
--keep                                         не перезаписывать готовые файлы
```
