# 112 Operator — Кинематографическая русская озвучка (Рация и Звонки 112)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Platform: Linux / Proton / Windows](https://img.shields.io/badge/Platform-Linux%20%2F%20Proton%20%2F%20Windows-green.svg)](#)
[![Audio: Studio Quality](https://img.shields.io/badge/Audio-WAV%2044.1kHz%2016--bit-orange.svg)](#)

Полноценная модификация с качественной, эмоциональной и кинематографической русской озвучкой для игры **112 Operator**:
1. **Переговоры экипажей по рации (563 аудиофайла)**: мужские и женские голоса, голливудские звуки рации (PTT-клики тангенты, сквилч-шум, динамическая компрессия), тактический армейско-полицейский сленг, крики под обстрелом, адреналин и крепкие выражения в критические моменты.
2. **Диалоги экстренных вызовов (Оператор и Звонящий)**: полная русская озвучка звонков со 100% соответствием официальному русскому тексту игры, передача эмоций (паника, плач, шок, боль, ярость), эффект телефонной линии и автоматическая синхронизация субтитров с русской речью.
3. **Реалистичный фоновый радиообмен (Chatter)**: живой эфир дежурной части МВД/МЧС (координация постов, ориентировки, проверка по базам).
4. **Официальная интеграция**: мод распознается движком игры и отображается в главном меню **«Моды» (Mods)** с возможностью включения и отключения.

## 🎙 Особенности озвучки

### 1. Переговоры по рации (Radio Transmissions)
- **`Male1` (Опытный командир экипажа)**: Низкий тембр, армейская дисциплина, сдержанная уверенность и чёткие доклады обстановки.
- **`Male2` (Штурмовик на адреналине)**: Быстрый темп, крики под обстрелом, сбитое дыхание и отборные фразы в бою:
  > *«Стреляют, сука! В укрытие! Срочно бронегруппу сюда, нас тут намертво прижали!»*  
  > *«Погоня, погнали! Он пытается свалить, хрен тебе! Перекройте улицу!»*  
  > *«Офицер ранен! Держись, братан, держись! Где скорая, мать вашу?!»*
- **`Female1` (Координатор / старший диспетчер)**: Собранная, чеканная командная речь.
- **`Female2` (Патрульная на передовой)**: Живые эмоции, надрыв при тяжелых ранениях:
  > *«По экипажу открыт огонь! Нас прижали огнем, скорей прикройте, сука!»*  
  > *«Офицер ранен! Дыши, дыши! Медиков сюда, быстро!»*
- **`Chatter` (Фоновый радиоэфир)**: Реалистичный фоновый радиообмен дежурной части города (пробивка по базам МВД, ориентировки, координация патрулей).

### 2. Экстренные звонки 112 (Calls & Dialogues)
- **100% совпадение с текстом игры**: Каждая реплика взята строго из официальной русской локализации игры (`StreamingAssets/Languages/ru-RU.txt`).
- **Диспетчер / Оператор**: Спокойный, профессиональный голос оператора в гарнитуре диспетчерского центра. Текст на экранных кнопках `{ЧТО СЛУЧИЛОСЬ?}` отделен от произносимой речи.
- **Звонящие в беде**:
  - Пол звонящего (мужской/женский) определяется по XML-сценарию вызова.
  - Динамическая модуляция эмоций: при панике и криках — учащенный темп и взволнованный голос; при травмах и боли — надрывный сдавленный голос; при опьянении — смазанная замедленная речь.
  - Акустика сотовой и телефонной связи (фильтрация полосы 350–3400 Гц с нелинейной сатурацией).
- **Идеальная синхронизация субтитров**: Игровой движок `CallWindow.PrintText` динамически рассчитывает темп вывода субтитров по фактической длине аудиоклипа (`AudioClip.length`), поэтому текст печатается строго в такт русской речи.

## 🛠 Установка

### Автоматическая установка (Linux / Steam Deck / Proton)
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/giddammit-crypto/112-operator-russian-voiceover.git
   cd 112-operator-russian-voiceover
   ```
2. Запустите скрипт установки:
   ```bash
   ./install.sh
   ```
   *(Если игра установлена в нестандартную директорию, укажите путь аргументом: `./install.sh "/путь/к/112 Operator"`)*.

3. Запустите игру в Steam, откройте меню **«Моды» (Mods)** и убедитесь, что мод **«Russian Radio Voiceover»** включен.

## 🔨 Сборка из исходников

### Требования
- [.NET 8.0 SDK](https://dotnet.microsoft.com/)
- Python 3.8+ (для скриптов генерации)
- FFmpeg (для акустической обработки)

### Сборка библиотеки мода
```bash
dotnet build RussianRadioMod/RussianRadioMod.csproj -c Release
```

### Применение патчей к Main.dll
```bash
dotnet run --project Patcher/Patcher.csproj
```

### Генерация аудиофайлов
```bash
python3 generate_cinematic_radio_full.py
python3 generate_russian_calls.py
```
